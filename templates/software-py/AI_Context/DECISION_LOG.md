# DECISION_LOG — 重要架构决策记录（ADR）

> 每个决策一条记录；决策推翻时新增条目并标记旧条目 SUPERSEDED，不删除历史。

## ADR-0001 记录架构决策（Record Architecture Decisions）

- **状态**：ACCEPTED（2026-11-15）
- **背景**：AI 双 Agent 协作中，架构决策若只存在于对话里，后续任务无法追溯依据。
- **决定**：所有影响公共接口、依赖、分层或数据格式的决策必须登记本文件。
- **后果**：Planner 引用决策时必须给出 ADR 编号；推翻决策需新增条目而非改写历史。

## ADR-0002 不可变实体 + Protocol 端口（<项目名>）

- **状态**：ACCEPTED（2026-11-15）
- **背景**：跨层传递可变实体导致隐式副作用；抽象基类带来继承耦合。
- **决定**：领域实体用 `@dataclass(frozen=True, slots=True)`；仓库等接缝用 `typing.Protocol` 结构化类型；infra 实现 Protocol，组合根注入。
- **备选与理由**：抽象基类（继承耦合，弃）；可变实体（隐式副作用，弃）。
- **后果**：状态推进必须 `dataclasses.replace`；新增仓库实现只需满足协议签名。
