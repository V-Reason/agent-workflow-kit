## 分组口径

- Worker 首过率按复杂度分组统计（L0 / L1 / L2 分列，L2 不与 L0 混算）。
- 每任务成本 = Secretary + Planner + Worker + Watchdog + 工具费用 / 验收通过数；订阅与 API 分账后合并计算。
- 失败任务也计入最终成功率分母，不剔除。
- 可选指标（有余力再记）：修复轮数、修改路径符合度、缓存命中率。

## 触发与动作

| 触发 | 动作 |
| --- | --- |
| 一次批准率 < 70% | 加载 `watchdog-inspector` 做流程复盘；先查任务书质量与上下文过期 |
| 首过率连续两周下滑 | 检查任务书可判定性与门禁真实性（编译/EditMode/审计） |
| 越权次数 ≥ 1 | 立即专项复盘；期间冻结路由表变更 |
| CEO 每周在上下文搬运/协调上 > 2 小时 | 检查 Secretary 备菜、FEED_DROP 与看板是否失效 |
| 月 L1+ 任务 ≥ 8 | 评估流程自动化与订阅调整 |
